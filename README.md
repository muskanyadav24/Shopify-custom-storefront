# 🛍️ Shopify Custom Storefront

A modern and fully responsive custom Shopify storefront theme built using Shopify Liquid, HTML, CSS, JavaScript, and Shopify Online Store 2.0 architecture.

This project includes reusable sections, custom storefront design, responsive layouts, and optimized Shopify theme structure for eCommerce stores.

---

# 🚀 Features

- Fully Responsive Design
- Custom Shopify Sections
- Featured Products Section
- Trending Products Layout
- FAQ Section
- Contact Form
- Service Features Bar
- Custom Footer
- Reusable Snippets
- Mobile Friendly UI
- Shopify Online Store 2.0 Compatible

---

# 🛠️ Technologies Used

- Shopify Liquid
- HTML5
- CSS3
- JavaScript
- Shopify CLI

# 📂 Project Structure

```bash
assets/        # CSS, JS, Images
blocks/        # Theme blocks
config/        # Theme settings
layout/        # Layout files
locales/       # Translation files
sections/      # Dynamic sections
snippets/      # Reusable snippets
templates/     # Shopify templates
```

# ⚡ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/muskanyadav24/Shopify-custom-storefront.git
```

## 2️⃣ Open Project Folder

```bash
cd shopify-custom-storefront
```

## 3️⃣ Login to Shopify Store

```bash
shopify login --store your-store.myshopify.com
```

## 4️⃣ Pull Theme Files

```bash
shopify theme pull
```

## 5️⃣ Start Development Server

```bash
shopify theme dev
```
